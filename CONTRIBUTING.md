# Contributing

Thanks for helping Grug think.

1. Fork the repository and create a focused branch.
2. Run `npm install` and `npm run dev`.
3. Keep every mock Grug reply inside the approved vocabulary.
4. Run `npm run lint` and `npm run build` before opening a pull request.
5. Explain behavior changes briefly in the pull request description.

Please keep the project small, browser-first, and honest about what is mocked.
